## Требования к окружению
* **Интерпретатор Python**: строго версия **3.12.14** (требуется для совместимости зависимостей).
* **СУБД**: 
  * SQLite (встроена в стандартную библиотеку Python)
  * PostgreSQL 15+ (для серверного этапа)
* **Инструменты**: Visual Studio Code, Git, DBeaver / pgAdmin.
* **Менеджер зависимостей**: `pip` (с файлом `requirements.txt`) или `poetry` (с файлами `pyproject.toml` и `poetry.lock`).

---

## Структура проекта
Проект организован в соответствии с требованиями воспроизводимости:

project/
├── .venv/                 # Виртуальное окружение (в git не отслеживается)
├── .vscode/               # Настройки редактора (settings.json)
├── data/
│   ├── raw/               # Исходные файлы данных (только чтение, в git не отслеживается)
│   ├── interim/           # Промежуточные сериализованные файлы (Parquet / Feather)
│   └── processed/         # Финальный очищенный набор данных
├── docs/                  # Документация и ER-диаграмма базы данных
├── notebooks/             # Исследовательские блокноты Jupyter (.ipynb)
├── sql/                   # SQL-скрипты схем баз данных (schema_sqlite.sql, schema_postgres.sql)
├── src/                   # Исходный код модулей проекта
│   ├── config.py          # Конфигурация путей и параметров схемы
│   ├── cleaning.py        # Набор функций для очистки данных
│   ├── pipeline.py        # Сквозной скрипт обработки с интерфейсом командной строки
│   ├── db.py              # Работа с базами данных (миграция схемы, загрузка).
│   ├── benchmark_postgres.py # Скрипт для замеров времени контрольных запросов в PostgreSQL.
|   ├── io_utils.py        # Функции для обработки файлов.
│   └── main.py            # Точка входа.
├── .env                   # Файл с реквизитами доступа к СУБД (в git не отслеживается)
├── .gitignore             # Исключения для Git
├── pyproject.toml         # Конфигурация Poetry
├── poetry.lock            # Блокировка зависимостей Poetry
├── requirements.txt       # Зависимости для pip
├── DATASET.md             # Паспорт набора данных
└── README.md              # Описание проекта

## Порядок развёртывания окружения и запуска

### Клонирование репозитория
Клонируйте репозиторий на локальную машину и перейдите в каталог проекта:

git clone [https://github.com/](https://github.com/)haeozo/Data.git
cd Data

## Создание окружения
py -3.12 -m venv .venv

### Активация окружения (для Windows PowerShell):
.venv\Scripts\Activate.ps1
###  Активация для macOS / Linux:
source .venv/bin/activate

### Установка зависимостей
pip install -r requirements.txt
